# minesweeper

一款简单的 Android 扫雷游戏，使用 Kotlin 与 Jetpack Compose 构建——无广告、无追踪，回归经典玩法。

[English](README.md)

## 功能特性

- **四档难度**
  | 难度 | 棋盘 | 雷数 |
  |------|------|------|
  | 标准 | 动态 | 格子总数 15% |
  | 初级 | 9 × 9 | 10 |
  | 中级 | 16 × 16 | 40 |
  | 高级 | 16 × 30 | 99 |
- **自适应棋盘** —— 标准档拉伸铺满屏幕，其余三档按比例缩放以适应。
- **首点必安全** —— 第一次点击永远不会踩雷，且会展开一片空白区域。
- **洪泛展开** —— 点击空白格会连锁展开整片连通区域。
- **快速翻开（chord）** —— 已翻开的数字格周围旗数匹配时，点击可自动翻开相邻格。
- **两种插旗方式** —— 长按，或使用专用的「插旗 / 翻开」切换按钮。
- **可选计时与最佳记录** —— 均可在设置中开关；最佳成绩按难度分别记录。
- **屏幕方向** —— 可锁定竖屏或允许旋转。
- **自定义启动图标** —— 简洁几何风格的地雷图形。

## 玩法

- 点击未翻开的格子将其翻开。
- 插旗（长按或切换按钮）标记可疑地雷。
- 点击已翻开的数字格快速翻开相邻格。
- 笑脸按钮重新开局——若游戏进行中，会先询问确认，避免误触。

## 环境要求

- Android 7.0（API 24）及以上

## 构建

用 Android Studio 打开项目运行，或在命令行构建 release APK：

```bash
./gradlew :app:assembleRelease
```

签名后的 release APK 输出至 `app/build/outputs/apk/release/app-release.apk`。

> **注意：** release 构建需要在项目根目录提供 `keystore.properties`（已被 git 忽略），其中包含 `storeFile`、`storePassword`、`keyAlias`、`keyPassword` 四项。
